# Видео: ГМО бактерия, която произвежда човешки инсулин

**Файл:** `gmo_insulin_ecoli.mp4` (1920×1080, 2:25 мин, с надписи на български и фонова музика)

**Организъм:** генно модифицирана бактерия *Escherichia coli* с вграден човешки ген за инсулин.
**Област на приложение:** медицина (лечение на диабет). Това е първото одобрено лекарство, получено от ГМО (Humulin, 1982 г.).
